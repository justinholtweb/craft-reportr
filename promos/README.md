# Plugin Store promo images

Marketing images for the Reportr listing on the Craft Plugin Store, in the same theme as the
plugin's page at [justinholt.com/plugins/craft-reportr](https://justinholt.com/plugins/craft-reportr).

## Building

```bash
./build.sh          # all slides
./build.sh "2 5"    # just slides 2 and 5
```

Output lands in `out/` as `reportr-promo-N.jpg`, 1920×1080 (rendered at 2× in headless Chrome, then
downsampled). **Promos are JPEG, never PNG** — `build.sh` converts with `sips` at quality 90.
Chrome sometimes exits non-zero after writing a good screenshot, so the script checks the file
rather than the exit code.

## Slides

| # | Slide | Shows |
|---|-------|-------|
| 1 | Cover — name, tagline, icon, $29 / $19 a year | — |
| 2 | Move in an afternoon | an unchanged Lab Reports advanced template, the importer, `craft.labreports` → `craft.reportr` |
| 3 | Ask before it runs | the run screen with typed parameters and a relative default |
| 4 | Point, click, export | a query report's element type, source and column keys |
| 5 | Seven formats, any filesystem | the formats, formula-injection neutralising, filesystems |
| 6 | Hear about the run that failed | schedule, failure-only delivery, the cron line |
| 7 | Bounded by disk, not memory | run history with rows, duration and peak memory, a failure reason |

The control-panel screens are hand-built HTML mocks (dark CP), not captures. Their labels — run
statuses, delivery options, parameter types, the run screen's buttons — are copied from `src/`;
change them together.

## Palette

Accent `#8A750C` (the icon's mustard) for fills; it is only 4.1:1 on the near-black ground, so
small type and highlights use `#E8CF6A` (12:1). `#C9A92A` is the mid tone and sage `#9FD3C7` the
secondary — the family's usual gold would disappear into the mustard. Jersey 20 display, Inter
body. CSS shell copied from `craft-xplain/promos`.

## Watermark

`assets/watermark.svg` is the three bars only, rounded and running off the bottom edge, and faded
out with a mask — the page is a big flat fill and at watermark scale reads as a box.
`assets/icon.svg` is a straight copy of `../src/icon.svg`.

`fonts.css` is generated by `build.sh` and gitignored.
